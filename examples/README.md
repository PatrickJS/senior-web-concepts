# Runnable examples

These examples are dependency-free ESM scripts. They are not meant to replace the generated concept pages; they are small runnable demos for concepts that are easy to model in Node.js.

```sh
npm run example:abort
npm run example:streams
npm run example:event-loop
npm run example:idempotency
npm run example:rate-limit
npm run example:saga
npm run example:hashing
npm run example:bloom
```
